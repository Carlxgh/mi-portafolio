# Mi Portafolio Web

## Descripción

Este proyecto consiste en el desarrollo de un sitio web tipo portafolio personal. El objetivo es aplicar conocimientos relacionados con el desarrollo web, organización de archivos, optimización de recursos, control de versiones y despliegue mediante un servidor web Apache.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Apache
- XAMPP
- Git
- GitHub
